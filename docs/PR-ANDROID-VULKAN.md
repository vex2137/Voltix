Android GPU identity currently reports only a name/API hint, and release APK inspection shows that libvoltix.so accounts for virtually all package size. This change adds cached, typed Vulkan discovery (IDs, actual driver properties, extensions, limits/features, heaps/types and optional estimated budget snapshots), while preserving EGL fallback and keeping Vulkan work off the UI thread. Vulkan heaps and process budget estimates never populate dedicated-VRAM or global-utilization metrics.

An Android-only size profile plus removal of unused Android desktop-renderer features reduced the measured APK candidate from 35,719,918 to 17,008,526 bytes (52.38%). Linux release settings and its software/GPU renderer choices remain unchanged. Android collectors pause in the background; explicit 16 KiB ELF/ZIP verification protects Android 15/16 compatibility.

Validation includes existing regression tests, typed Vulkan loader/error/fallback tests, memory-semantics/localization tests, a Mesa Lavapipe integration probe, APK/ELF/symbol/signature/resource checks and Linux AppImage build/launch checks. See docs/ANDROID-VULKAN-APK.md and the Actions artifacts for exact results and size reports. No physical Android/Mali visual or performance verification is claimed. No merge is requested or performed automatically.
